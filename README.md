# REPLAY

Repositório do **SetPoint**: sistema de gestão e agendamento de quadras de areia, com **replays instantâneos** por câmera.

Todo o sistema está na pasta [`SetPoint/`](SetPoint/): back-end Laravel, front-end Vue, serviço de captura de replays e documentação.

- **Replays (hardware, fluxo e código):** [SetPoint/docs/REPLAYS.md](SetPoint/docs/REPLAYS.md)
